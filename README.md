# Data Warehouse & Analytics Project

Welcome to the **Data Warehouse & Analytics Project** repository! 🚀

This project demonstrates a complete end-to-end data warehousing and analytics solution using SQL Server. It covers the entire journey—from designing a modern data warehouse and building ETL pipelines to creating business-ready analytical models and SQL reports. This repository is part of my data analytics portfolio and reflects industry best practices in data engineering, data modeling, and business intelligence.

---

## 🏗️ Data Architecture

This project follows the **Medallion Architecture** consisting of **Bronze**, **Silver**, and **Gold** layers.
<img width="827" height="464" alt="Untitled Diagram drawio (2)" src="https://github.com/user-attachments/assets/32768abf-8dee-464e-b789-875721588119" />


### 🥉 Bronze Layer

* Stores raw data directly from source systems.
* Imports ERP and CRM datasets from CSV files into SQL Server.
* Preserves the original data without transformations.

### 🥈 Silver Layer

* Cleans, standardizes, validates, and transforms raw data.
* Handles missing values, duplicates, and data quality issues.
* Prepares reliable datasets for analysis.

### 🥇 Gold Layer

* Creates business-ready datasets using a Star Schema.
* Builds Fact and Dimension tables optimized for analytical queries.
* Supports dashboards, reporting, and business intelligence.
